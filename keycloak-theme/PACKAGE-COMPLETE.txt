ACTIVATION STEPS
================

1. Access Keycloak Admin Console:
   https://auth.unicorncommander.ai/admin

2. Login with admin credentials

3. Select your realm

4. Navigate to: Realm Settings → Themes

5. Set Login Theme to: uc-1-pro

6. Click Save

7. Test: https://auth.unicorncommander.ai/realms/YOUR-REALM/account

CUSTOMIZATION GUIDE
===================

Change Colors:
  Edit: uc-1-pro/login/resources/css/login.css
  Modify: :root { --uc1-purple-primary: #YOUR_COLOR; }

Change Text:
  Edit: uc-1-pro/login/login.ftl
  Modify: <h1 class="uc1-title">Your Title</h1>

Add Logo:
  Copy: colonel-logo.png
  To: uc-1-pro/login/resources/img/colonel-logo.png

Add JavaScript:
  Create: uc-1-pro/login/resources/js/login.js
  Reference: In theme.properties: scripts=js/login.js

Add Translations:
  Create: uc-1-pro/login/messages/messages_XX.properties

TROUBLESHOOTING
===============

Theme Not Showing:
  1. Check files exist: docker exec uchub-keycloak ls /opt/keycloak/themes/uc-1-pro
  2. Check permissions: docker exec uchub-keycloak ls -la /opt/keycloak/themes/uc-1-pro
  3. Clear browser cache: Ctrl+Shift+R
  4. Check logs: docker logs uchub-keycloak | grep -i theme

Logo Not Displaying:
  1. Verify file exists: ls keycloak-theme/uc-1-pro/login/resources/img/colonel-logo.png
  2. Check browser console for 404 errors
  3. Verify file format (PNG, JPG, SVG)
  4. Check file permissions

Styles Not Applied:
  1. Clear browser cache (hard reload)
  2. Check CSS loaded in DevTools Network tab
  3. Verify theme.properties has correct CSS path
  4. Check for CSS syntax errors in browser console

Container Errors:
  1. Fix permissions: docker exec -u root uchub-keycloak chown -R keycloak:keycloak /opt/keycloak/themes/uc-1-pro
  2. Restart container: docker restart uchub-keycloak
  3. Check logs: docker logs uchub-keycloak
